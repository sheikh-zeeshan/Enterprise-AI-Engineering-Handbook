# AI Agent Instructions

1. Discover the repository before modifying it.
2. Make focused changes within the current task scope.
3. Follow `/instructions/architecture.md`, `/instructions/coding-standards.md`, and `/instructions/testing.md`.
4. Keep domain behavior out of API endpoints and EF Core configurations.
5. Use direct application services for the current baseline; CQRS is deferred.
6. Do not remove tests or weaken validation to obtain a passing build.
7. Report files changed, validation commands, results, assumptions, and remaining risks.
